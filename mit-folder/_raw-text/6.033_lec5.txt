• Threads virtualize a processor so that we can share it
among programs. yield() allows the kernel to suspend
the current thread and resume another.
• Condition Variables provide a more efficient API for
threads, where they wait for an event and are notified
when it occurs. wait() requires a new version of yield(),
yield_wait() .
• Preemption forces a thread to be interrupted so that we
don’t have to rely on programmers correctly using yield().
Requires a special interrupt and hardware support to
disable other interrupts.
